# 탱크어붐 데이터 도감

Tank-a-Boom의 탱크·스킬·특성·부품·칩·스킨·모드와, 게임 화면에서는 볼 수 없는 세부 수치와 출시 예정 콘텐츠를 한곳에 모은 비공식 팬 사이트입니다.

- 사이트: https://jinavav15000-star.github.io/tankaboom-db/
- 데이터 기준: iOS 클라이언트 0.29.2 (빌드 0.1218)
- 외부 라이브러리 없이 정적 HTML 하나(`index.html`)와 데이터(`data.js`, `tables/*.json`)로 동작합니다.

## 담은 것
- 탱크 30대: 레벨별 내구도·장갑·피해, 재장전·분산·포탄, 에너지, 엔진 곡선, 부품 슬롯, 강화 단계, 칩 풀, 스킨
- 빌드 시뮬레이터: 레벨·강화·제조사 기술·부품·칩을 고르면 능력치 변화 계산, 기준별 최강 부품 조합과 추천 칩
- 부품·칩·스킬 설명의 빈칸을 능력 데이터 실제 값으로 채움
- 비교, 스킬·특성, 부품 346종, 칩 102종, 오퍼레이터, 스킨 364종, 모드·맵, 제조사·리그·메달·장비
- 미공개·출시 예정: 번역 전 탱크, 미공개 모드·맵, 숨김 스킨, 영어로만 있는 문구
- 원본 DataTable 121개 브라우저
- 게임 UI 이미지 2,606장: 탱크·스킨 렌더, 파워 무브·특성·부품·칩 아이콘, 오퍼레이터, 맵·모드, 메달, 프로필 꾸미기 (#gallery)

## 넣지 않은 것
사운드·3D 모델, 서버 주소나 통신 방식, 계정 관련 정보.

‘출시 예정’ 표시는 번역 유무·스킨·칩 구성으로 판단한 추정입니다. 게임 이름·이미지·텍스트 등 콘텐츠의 권리는 개발사와 각 권리자에게 있습니다.
